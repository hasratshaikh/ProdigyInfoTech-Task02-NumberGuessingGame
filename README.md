# Prodigy InfoTech Internship – Task 02

## Number Guessing Game

A simple and interactive number guessing game developed using Python as part of the Prodigy InfoTech Software Development Internship Program.

## Features

- Generates a random number between 1 and 100.
- Allows users to guess the secret number.
- Provides hints when the guess is too high or too low.
- Counts the number of valid attempts.
- Handles invalid inputs and numbers outside the allowed range.
- Allows users to play multiple rounds.

## Technologies Used

- Python
- Random Module

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/hasratshaikh/ProdigyInfoTech-Task02-NumberGuessingGame.git
```

### 2. Navigate to the Project Directory

```bash
cd ProdigyInfoTech-Task02-NumberGuessingGame
```

### 3. Run the Game

```bash
python main.py
```

## How to Play

1. The computer selects a random number between 1 and 100.
2. Enter your guessed number.
3. Follow the hints to guess higher or lower.
4. Continue until you guess the correct number.
5. The game displays the total number of attempts.
6. Choose whether to play again.
